Create Your Own Game – Step by Step

1. 🟢 STEP 1 – Come up with a game idea.Think about what the game should be about. Write down your idea in a few words.

2. 🟢 STEP 2 – Tell AI what you want to create. Open ChatGPT or another AI service. Describe the game and what the player should do.

3. 🟢 STEP 3 – Decide how the game should be controlled. Choose arrow keys, touchscreen, mouse or game controller. Tell AI how the game should be controlled.

4. 🟢 STEP 4 – Ask AI to create the game. Ask AI to write the whole game as HTML code.Example: “Create the whole game as an HTML file that I can open in a web browser.”

5. 🟢 STEP 5 – Copy or download the code. Copy the HTML code or download the HTML file from AI. The file should end with .html.

6. 🟢 STEP 6 – Save the file correctly. Open Notepad, paste the code and choose Save As. For example, type mygame.html and choose All Files.⚠️ Check that the file does not end with .html.txt.

7. 🟢 STEP 7 – Test the game. Find the HTML file and double-click it. The game opens in your web browser. Play it and check that the controls work.

8. 🟢 STEP 8 – Give AI feedback.Tell AI what you want to change.Example: “The game is too easy. Make the enemies faster.”

9. 🟢 STEP 9 – Test again. Save the new version and open the HTML file again. Play it and see if the change works. Repeat until you are happy.

10. 🟢 STEP 10 – Get the game ready for Game_room. Check that the game and controls work, that the game has a name, and that the HTML file works.

11. 🟢 STEP 11 – Upload the game to Game_room. Go to Game_room and choose the category where you want to publish your game. Upload your .html file and use the password if needed.

12. 🟢 STEP 12 – Play your published game. Go to the category where you uploaded your game. Find your game and start it. Check that everything works after publishing.

13. 🟢 STEP 13 – Share the game! Copy the link to your game and share it with friends, family or other participants.

14. ⭐ TRY IT YOURSELF! ☐ Come up with a game idea ☐ Tell AI ☐ Decide the controls ☐ Create the HTML game ☐ Save as .html ☐ Test the game ☐ Give AI feedback ☐ Improve the game ☐ Upload to Game_room ☐ Share the link

15. 🆘 IF YOU GET STUCK! AI question feels difficult: Describe in your own words what you want to do. HTML opens as text: Check that the file ends with .html and that All Files was selected. The game does not work: Tell AI exactly what happens and ask AI to fix the problem. I broke the game: Ask AI to create a new version and save working versions with different names. Can't move forward? Ask for help.
